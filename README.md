# Земли Рассвета — мини-MMO на three.js

Изометрическая мини-MMORPG в браузере: город с торговцем, три зоны мобов (слизни → волки → скелеты),
три босса с телеграфируемыми атаками, лут с редкостью, прокачка, чат и совместная игра без своего сервера.

## Запуск локально

ES-модули не работают через `file://`, нужен любой статический сервер:

```bash
python -m http.server 8000
```

Открыть http://localhost:8000

## Деплой на GitHub Pages

1. Создать репозиторий и залить туда `index.html`, `style.css`, папку `js/`, `README.md` (и пустой файл `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<ник>.github.io/<репозиторий>/`.

Сборка не нужна: three.js и Trystero подгружаются с CDN jsdelivr.

## Как работает мультиплеер (и почему не нужен сервер)

GitHub Pages умеет отдавать только статические файлы, запустить там сервер нельзя. Поэтому игра использует
**P2P через WebRTC** (библиотека [Trystero](https://github.com/dmotz/trystero)):

- браузеры игроков находят друг друга через публичные **Nostr-релеи** (это только «знакомство»);
- дальше данные идут напрямую между браузерами;
- «сервер» поэтому всегда доступен ровно настолько, насколько доступны GitHub Pages и публичные релеи.
  Платить, держать что-то включённым или бояться, что сервер «уснёт», не нужно.

Что синхронизируется: позиции и анимации игроков, ник, уровень, HP, чат и **урон по боссам**
(бьёте босса вдвоём, и его HP падает у обоих).
Что локально: обычные мобы и лут у каждого свои (как «инстансы»), прогресс хранится в `localStorage`.

Ограничения P2P:
- ~5–10% игроков за строгим NAT (некоторые мобильные/корпоративные сети) не смогут соединиться без TURN-сервера;
- каждый связан с каждым, комфортно до ~20–30 человек в одной комнате;
- нет античита: прогресс хранится у игрока.

Чтобы разделить игроков на свои комнаты, поменяйте `APP_ID` / `ROOM` в `js/net.js`.

## Если захочется настоящий сервер

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Cloudflare Workers + Durable Objects** | бесплатный тариф, WebSocket, не «засыпает» надолго | нужно переписать логику мира на сервер |
| Colyseus / Node.js на Fly.io, Render, Railway | удобный фреймворк для игр | бесплатные тарифы засыпают, первый вход ~30–60 с |
| Oracle Cloud Always Free VM | всегда включён, бесплатно | нужно администрировать самому |

Клиент при этом остаётся на GitHub Pages, меняется только `js/net.js`.

## Управление

- **ЛКМ**: идти (можно держать) / атаковать монстра / поговорить с торговцем
- **WASD**: ходить, **Пробел**: атаковать ближайшего, **Tab**: сменить цель
- **1**: Вихрь, **2**: Исцеление, **3 / Shift**: Рывок (уклонение от снарядов), **4 / R**: Зелье
- **I**: инвентарь, **Enter**: чат, **колесо**: зум, **H**: скрыть подсказку

## Боссы

| Босс | Ур. | Где | Способности |
|---|---|---|---|
| Король Слизней | 5 | луга, запад по карте | удар по площади, призыв слизней |
| Древний Голем | 11 | волчий лес, восток | удар, камнепад |
| Лич Моргрим | 16 | мёртвые земли, север | снаряды, метеоры, нова, призыв скелетов |

На 50% HP боссы впадают в ярость и атакуют чаще. Красные круги на земле показывают, куда придётся удар: выходите из них.
